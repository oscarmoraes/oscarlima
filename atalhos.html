Teclado Padrão Brasileiro (Norma ABNT2)

O teclado ABNT2 possui a tecla Ç e posiciona os caracteres de pontuação (como ;, /, ? e ~) de forma única. Neste guia, atalhos do VS Code foram especialmente adaptados para funcionar de primeira no seu teclado!

🪟 1. Atalhos Fundamentais do Windows

14 Atalhos
📝 Edição & Seleção de Texto
📋
Copiar
Salva o texto ou arquivo selecionado na memória do computador sem apagá-lo.
💡 No dia a dia: Selecione um código, dê Ctrl+C e leve para outro arquivo.
Ctrl + C
📄
Colar
Insere exatamente na posição do cursor o conteúdo que você copiou anteriormente.
💡 No dia a dia: Posicione o cursor onde deseja o texto e dê Ctrl+V.
Ctrl + V
✂️
Recortar
Copia o item selecionado e o remove de onde ele estava.
💡 No dia a dia: Perfeito para mudar um bloco de código de lugar.
Ctrl + X
↩️
Desfazer (O Salva-Vidas)
Cancela imediatamente a última alteração feita. Apagou algo sem querer? Use já!
⭐ Dica: Pode ser pressionado várias vezes seguidas para voltar no tempo.
Ctrl + Z
↪️
Refazer
Avança novamente caso você tenha apertado Ctrl+Z além da conta.
💡 No dia a dia: Restaura o que o Desfazer acabou de apagar.
Ctrl + Y
🔘
Selecionar Tudo
Marca todo o texto da página, código do arquivo ou todos os itens de uma pasta.
💡 No dia a dia: Ctrl+A seguido de Ctrl+C copia o arquivo inteiro.
Ctrl + A
🗂️ Janelas, Multitarefa & Produtividade
🔁
Alternar Entre Janelas
Mude de um aplicativo para outro sem precisar tirar a mão do teclado para clicar na barra.
💡 Como usar: Segure Alt e vá apertando Tab.
Alt + Tab
🗃️
Histórico de Cópia (Clipboard)
Abre um menu com os últimos 25 itens que você copiou para colar qualquer um deles.
⚡ Super poder: Copie 4 coisas seguidas e cole na ordem desejada.
⊞ Win + V
📸
Captura de Tela Seletiva (Print)
Permite selecionar com o mouse apenas um retângulo da tela para copiar a foto do erro ou código.
💡 No dia a dia: Dê o atalho, selecione a área e dê Ctrl+V no Discord/WhatsApp.
⊞ Win + Shift + S
🖥️
Mostrar / Ocultar Área de Trabalho
Minimiza instantaneamente todas as janelas para visualizar seu Desktop.
💡 No dia a dia: Aperte novamente para restaurar todas as janelas.
⊞ Win + D
📁
Abrir Explorador de Arquivos
Abre o gerenciador de pastas do Windows de imediato.
💡 No dia a dia: Chega de caçar o ícone amarelo na barra de tarefas!
⊞ Win + E
⚡
Gerenciador de Tarefas Direto
Abre direto a tela para finalizar programas que travaram.
💡 Vantagem: Muito mais rápido do que dar Ctrl+Alt+Del.
Ctrl + Shift + Esc
🏷️
Renomear Arquivo / Pasta
Permite editar o nome do item selecionado sem o risco de abri-lo por engano.
💡 No dia a dia: Funciona tanto no Windows quanto dentro do VS Code.
F2
🔒
Bloquear Computador
Bloqueia a sessão do Windows exigindo senha ao retornar.
🛡️ Segurança: Use sempre que levantar da mesa na aula ou no estágio.
⊞ Win + L

🌐 2. Atalhos de Navegação Web (Chrome, Edge, Firefox)

10 Atalhos
📑 Controle de Abas & Janelas
➕
Nova Aba
Abre uma nova guia no navegador imediatamente com foco na pesquisa.
💡 No dia a dia: Aperte Ctrl+T e já comece a digitar a busca.
Ctrl + T
❌
Fechar Aba Atual
Encerra a guia visualizada sem precisar acertar o 'x' minúsculo do mouse.
💡 No dia a dia: Funciona também para fechar abas de código no VS Code!
Ctrl + W
🔮
Reabrir Aba Fechada por Engano
Restaura a última aba que você fechou acidentalmente com todo o histórico intacto.
⭐ Indispensável: Evita o desespero de perder artigos ou pesquisas.
Ctrl + Shift + T
➡️
Alternar Entre Abas
Pula para a próxima aba à direita. Use com Shift para voltar à esquerda.
💡 No dia a dia: Navegue por 10 abas abertas sem tocar no mouse.
Ctrl + Tab
🕵️
Janela Anônima / Privada
Abre o navegador sem cookies ou contas logadas.
💡 Para Devs: Excelente para testar telas de login e cadastros do zero.
Ctrl + Shift + N
🔍 Pesquisa & Ferramentas de Desenvolvimento
🔗
Focar na Barra de Endereço (URL)
Seleciona a barra de links pronta para você digitar um novo endereço ou pesquisar.
💡 No dia a dia: Aperte Ctrl+L, dê Ctrl+C e copie o link da página em 1 segundo.
Ctrl + L ou Alt + D
🔎
Buscar / Localizar na Página
Abre o campo de busca interna para encontrar termos na página ou documentação.
💡 No dia a dia: Ache rapidamente o erro ou a função que procura.
Ctrl + F
⚡
Recarregar Limpando o Cache
Força o navegador a baixar os arquivos CSS/JS novos sem usar versões antigas em memória.
🔥 Dica de Ouro: Mudou o CSS mas a tela não mudou? Use este atalho!
Ctrl + F5 ou Ctrl + Shift + R
🛠️
Inspecionar Elemento (DevTools)
Abre o console de erros JavaScript, o painel de redes e o editor ao vivo de HTML/CSS.
💻 Essencial: A principal ferramenta de depuração de todo programador web.
F12 ou Ctrl + Shift + I
🔍
Ajustar / Resetar Zoom
Aumenta (+), diminui (-) ou retorna a página para o tamanho padrão 100% (0).
💡 No dia a dia: Excelente para testar responsividade de layouts.
Ctrl + + / - / 0

💻 3. Atalhos do Visual Studio Code (VS Code)

16 Atalhos
⚡ Manipulação & Edição de Linhas
💬
Comentar / Descomentar Linha (ABNT2)
Transforma a linha ou seleção em comentário (ou remove as barras de comentário).
⚠️ No ABNT2: A tecla padrão no Brasil é o ponto e vírgula ( ; )!
Ctrl + ; ou Ctrl + /
👯
Duplicar Linha de Código
Clona a linha atual inteira para baixo ou para cima instantaneamente sem precisar selecionar!
⚡ Agilidade: Nunca mais copie e cole para repetir uma linha.
Shift + Alt + ↓ ou ↑
↕️
Mover Linha para Cima / Baixo
Desloca a linha ou bloco selecionado para cima ou para baixo com total fluidez.
💡 No dia a dia: Reorganize a ordem de variáveis e funções em segundos.
Alt + ↑ ou ↓
🗑️
Apagar Linha Inteira
Deleta a linha inteira onde está o cursor sem precisar selecionar com o mouse.
💡 No dia a dia: Muito mais limpo do que segurar o Backspace.
Ctrl + Shift + K
✨
Formatar Código (Indentação)
Alinha chaves, quebras de linha e espaços do arquivo de forma profissional e legível.
⭐ Indispensável: Código bagunçado? Aperte este atalho e veja a mágica!
Shift + Alt + F
🎯 Seleções Múltiplas & Produtividade Extrema
🪄
Selecionar Próxima Ocorrência
Selecione uma palavra ou tag e aperte repetidamente para editar todas juntas com múltiplos cursores.
⚡ Produtividade: Altere o nome de uma variável repetida no código simultaneamente.
Ctrl + D
💥
Selecionar Todas as Ocorrências
Cria cursores em todas as palavras idênticas do arquivo inteiro de uma só vez.
💡 No dia a dia: Renomeie uma classe CSS repetida 30 vezes em 1 segundo.
Ctrl + Shift + L
🖱️
Inserir Múltiplos Cursores Livres
Segure o Alt e vá clicando com o mouse em linhas diferentes para digitar nelas ao mesmo tempo.
💡 No dia a dia: Adicione aspas ou vírgulas em 10 itens de um array juntos.
Alt + Clique com Mouse
💡
Forçar Autocompletar (IntelliSense)
Reabre a lista suspensa com sugestões de métodos, variáveis, tags HTML e CSS.
💡 No dia a dia: Esqueceu o nome exato de uma propriedade? Use este atalho!
Ctrl + Espaço
📂 Painéis, Arquivos & Terminal
🎛️
Paleta de Comandos Geral
O centro de controle do VS Code. Permite rodar qualquer comando, instalar temas ou extensões.
⭐ Regra: Se você não sabe o atalho de algo, procure por aqui!
Ctrl + Shift + P ou F1
⚡
Localizar e Abrir Arquivo Rápido
Encontre qualquer arquivo do projeto digitando partes do nome, sem abrir pastas.
💡 No dia a dia: Digite index ou style e tecle Enter.
Ctrl + P
💻
Abrir / Fechar Terminal Embutido
Exibe o terminal na parte inferior do editor para rodar git, npm, python ou php.
⚠️ No ABNT2: Use Ctrl + ' (aspas simples) ou Ctrl + J.
Ctrl + ' ou Ctrl + J
📁
Mostrar / Ocultar Barra Lateral
Esconde a árvore de arquivos para liberar mais espaço de tela para o código.
💡 No dia a dia: Ganhe foco total ao programar em telas menores.
Ctrl + B
🪟
Dividir Tela em Colunas (Split)
Abre o código em duas colunas paralelas para visualizar o HTML e o CSS lado a lado.
💡 No dia a dia: Edite seu código enquanto consulta outro arquivo sem alternar abas.
Ctrl + \
🎯
Pular Direto para a Linha
O console acusou erro na linha 145? Digite o número da linha e pule até ela instantaneamente.
💡 No dia a dia: Aperte o atalho, digite o número e dê Enter.
Ctrl + G
💾
Salvar Arquivo
Grava as alterações feitas no documento atual.
💡 Dica Pro: Use Ctrl+K seguido de S para salvar todos os arquivos abertos de uma vez.
Ctrl + S
